## What to build

Review the sample-day assumptions used by the prototype: Friday date, inferred semester week, period-to-clock mapping, and the 08:00-09:00 temporary meeting.

This is a review gate, not production work. The result should be a short note in the issue or PR confirming whether the sample data is acceptable for MVP development demos.

## Acceptance criteria

- [ ] Confirm that `2026-05-22` is the intended Friday demo date.
- [ ] Confirm whether the assumed week-13 Friday classes are acceptable as mock data.
- [ ] Confirm whether the 08:00-09:00 meeting is acceptable as the temporary-event demo case.
- [ ] If any assumption is wrong, update the sample data before implementation starts.
